LayerClean 与水墨工坊可直接在线使用。素材收集器网页版可导入、筛选并打包素材；网站采集、B站已购下载与音视频合并使用 Windows 完整版。

01 / 下载整合包

下载仓库 Releases 中的 CreativeHub-Windows.zip，完整解压后保留所有子目录。

前往下载 ↗
02 / 一次启动

双击 Start-Hub.bat。首次启动会准备 LayerClean 依赖，随后打开集合页。使用期间请保留启动窗口。

03 / 开始使用

在集合页打开需要的工具。结束后关闭启动窗口；素材收集器也可通过系统托盘退出。

LayerClean · 图层清理

网页版无需安装，支持 PNG 或含 PNG 的 ZIP。导入后检测、查看预览再导出。当前清理模板针对原工具内置的绿色重复标志与文字，其他样式不保证识别。导出会校验原尺寸与透明通道。

工作台地址：127.0.0.1:8876。如已有程序运行，启动器会复用它。

素材收集器 · 素材与 B站会话

保留提供的“B站已购内容会话修复版”程序。B站内容请在原工具内按提示同步本人已登录账号，浏览器扩展位于 apps/collector/browser-extension。账号会话不上传到集合网站。

工作台地址：127.0.0.1:8765。下载权限仍取决于账号和来源网站。

打不开本地工具怎么办？

先完整解压并运行 Start-Hub.bat；不要直接在压缩包里启动。若首次安装失败，检查 Python 3.10 或以上版本与网络，然后重试。手机可以使用水墨工坊，本地工具需要在运行程序的 Windows 电脑上打开。
